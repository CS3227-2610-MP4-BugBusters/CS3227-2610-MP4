# Investigation checklist demo

Run `npm ci` and `npm run dev` in this directory. Select Developer to edit, save, and share steps. Switch to Reporter or Maintainer to see the shared copy. The demo uses one synthetic report and keeps state in memory until reload.

Run `npm run verify` for type checking, UI tests, and a build. These tests exercise the demo behaviour. Real authentication, report assignment, persistence, version conflicts and closure races need the shared API and PostgreSQL.
