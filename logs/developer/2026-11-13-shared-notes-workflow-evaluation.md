# Shared investigation notes: workflow evaluation

## Summary

The requested feature separates the Developer's private notes from a saved shared-note draft and an explicitly published version visible to Maintainers. The user confirmed that Reporters should not have access. This is a full-path change because it affects authorization, shared PostgreSQL data and report lifecycle transitions. The frontend and backend changes were implemented, the independent candidate passed the authenticated PostgreSQL suite, and the security reviewer passed the recheck. A live browser/deployed check and provider-specific tests were outside this run.
